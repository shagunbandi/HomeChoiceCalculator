# Home Choice Calculator

A simple mortgage calculator that helps you compare the costs of buying versus renting a home.

## Features

- Calculate monthly mortgage payments
- Compare buying vs. renting costs over time
- Find break-even point between buying and renting
- Calculate tax benefits of homeownership
- Visualize amortization schedule

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```

## Usage

1. Enter your property details (purchase price, down payment, etc.)
2. Enter your mortgage details (interest rate, term, etc.)
3. Enter your rental comparison details
4. Click "Calculate" to see the results

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- shadcn/ui components
- React Hook Form with Zod validation
- Recharts for data visualization
